# 💻 Desenvolvimento de Sistemas — Estudos & Práticas em Java

[![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=java&logoColor=white)](https://www.java.com/)
[![GitHub repo size](https://img.shields.io/github/repo-size/sahmlo/desenvolvimentoDEsistemas?style=for-the-badge&color=blue)](https://github.com/sahmlo/desenvolvimentoDEsistemas)

Repositório destinado ao armazenamento de exercícios, atividades práticas e projetos desenvolvidos durante as aulas da disciplina de **Desenvolvimento de Sistemas**. O foco principal é o aprendizado da linguagem **Java**, abrangendo desde a sintaxe básica e estruturas de controle até Programação Orientada a Objetos (POO), manipulação de arquivos e tratamento de exceções.

---

## 📂 Estrutura do Repositório

| Pasta / Módulo | Descrição do Conteúdo |
| :--- | :--- |
| 🚀 `IntroducaoAJava` | Conceitos fundamentais, sintaxe básica e estrutura inicial de programas em Java. |
| 🔀 `EstruturaCondicionais` | Exercícios práticos utilizando estruturas de decisão (`if`, `else`, `switch-case`). |
| 🔁 `ArraysFor` | Atividades com laços de repetição utilizando a estrutura `for`. |
| 🔄 `ArraysWhile` | Exercícios práticos com laços `while`, `do-while` e comparações iterativas. |
| 📊 `Vetores` | Introdução e manipulação de vetores (arrays unidimensionais). |
| 📋 `ArrayList` | Gerenciamento de listas dinâmicas com a classe `ArrayList` (ex: gerenciamento de nomes). |
| 📦 `Poo` | Conceitos de **Programação Orientada a Objetos** (Classes, Métodos, Atributos e Exercícios de Pagamento). |
| ⚠️ `Exececoes` | Tratamento e manipulação de exceções e erros em Java (`try-catch`, `finally`). |
| 📁 `File` | Leitura, escrita e manipulação de arquivos (I/O) em Java. |
| 🔲 `CaixaOpçoes` | Exercícios práticos utilizando caixas de diálogo / menus interativos de seleção. |
